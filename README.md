# First Hebrew: Meet the Letters

Interactive lessons for Alef, Bet, Vet, Gimel, Daled, and Heh. Choose a letter, click its big symbol to hear the consonant (Alef stays silent), then choose Yes to try Kamatz, Patach, and Segol. No returns to that letter’s opening screen. Switching letters stops audio and resets the interaction.

Open `index.html` in a browser. No build or installation is required. Bundled WAV clips use synthesized phonemes for the consonants and vowel combinations. Kamatz and Patach use /ɑː/ here; Segol uses /ɛː/. Bet is shown with its dagesh, and Vet without it. Audio plays on a click without requiring a browser speech voice or external service.
