# Meet Alef

A simple interactive Hebrew lesson. Click the big Alef, choose Yes, then click Alef with Kamatz, Patach, or Segol to hear its vowel sound. No returns to the opening screen.

Open `index.html` in a browser. No build or installation is required. Bundled WAV recordings use synthesized IPA vowels: /ɑː/ for Kamatz and Patach, /ɛː/ for Segol. Audio plays directly on a click without requiring a browser speech voice or external service.

Published with GitHub Pages: https://esemmelman.github.io/hebrew04/
